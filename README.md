# VirusAI — Web Landing Page

Official web landing page for **VirusAI**: The Private Offensive-Security Workspace.

Designed with the official VirusAI visual identity:
- **Jet Black**: `#0B0B0C`
- **Smoke Grey**: `#8A8D93`
- **Cherry Red**: `#C8102E`

## Features

- **Workspace Showcase**: Interactive preview of the Tri-Pane IDE, Proxy Workbench, Fail-Closed Scope Gate, Multi-Shell Terminal, Security Browser, Autonomous AI Agents, and Skill Library.
- **Cross-Platform Downloads**: Dedicated tabs and 1-click terminal install commands for **Windows**, **Linux**, and **macOS** with auto-OS detection.
- **System Architecture**: Overview of internal localhost ports (Engine `:8790`, Proxy `:8791`, PostgreSQL `:8792`).
- **Zero Runtime Dependencies**: Pure HTML5, modern CSS, and vanilla JavaScript. 100% compatible with GitHub Pages, Vercel, Netlify, and Cloudflare Pages.

## Deployment to GitHub Pages

1. Go to repository Settings > **Pages**.
2. Under **Build and deployment**, set source to **Deploy from a branch**.
3. Select `main` branch and `/ (root)`.
4. Click **Save**.
