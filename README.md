## Overview
VirusAI is an autonomous, private offensive-security workspace and penetration testing IDE that consolidates terminal, instrumented browser, Monaco code editor, and recording proxy into a single desktop application backed by a self-supervised PostgreSQL 16 cluster.

## Features
- **Interactive Workspace Showcase**: Live screenshots and demonstrations of the Tri-Pane IDE, Proxy Workbench with fail-closed scope gate, Multi-shell PTY manager, Security Browser, and autonomous AI agents.
- **Operator Runbook & Documentation**: Technical references on installation, cold-start lifecycle, scope enforcement, and local secrets encryption.
- **Binary Distribution Hub**: Windows installer and portable executable downloads with verified SHA-256 checksums.
- **Zero Runtime Dependencies**: Pure static bundle (HTML5, modern CSS, vanilla JavaScript). Ready for instant hosting on GitHub Pages, Vercel, or Netlify.
