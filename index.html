Core Principles

Engineered Without Compromise

01

Zero Prerequisites

Supervises its own private PostgreSQL 16 cluster. No Docker, no WSL configuration, and no external database daemon needed to operate.

02

Fail-Closed Scope Gate

The recording proxy refuses out-of-scope requests before they leave the host. Target scope is enforced across both human and agent actions.

03

Tri-Pane Workspace

Terminal, proxied browser, and Monaco file editor live in a single window with draggable dividers and detachable copilot tabs.

04

Omni Perception Agent

The AI planner simultaneously ingests active terminal buffers, live browser DOM, open editor code, and recorded proxy traffic flows.

05

Evidence Over Assertion

Findings are accepted only with reproducible artifacts: control request, attack request, diff isolation, and confirmed re-test replay.

06

100% Local & Encrypted

Zero telemetry. No phone-home analytics. Model provider credentials and proxy secrets are encrypted at rest on your filesystem.

Architecture

Local Engine & Bound Ports

VirusAI coordinates independent background services bound strictly to localhost, preventing collision with existing system tools or proxy suites.
