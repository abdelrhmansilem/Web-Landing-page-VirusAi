Operator Field Guide

Documentation & Runbook

Technical reference and operational standards for VirusAI v0.1.0-beta.1.

LIFECYCLE · ZERO PREREQUISITES

Installation & Cold Boot

VirusAI ships as a self-contained executable that supervises its own private PostgreSQL 16 cluster. No external dependencies, admin rights, or database installations required.

1. Choose Your Distribution Package

- Setup Installer (.exe): Installs to user application directory, establishes desktop shortcuts, and registers file associations.
- Portable (.exe): Standalone executable. Run directly from any directory or removable drive without system modification.

2. Cold Start Execution (30-45 Seconds)

Upon initial launch, the Go engine automatically provisions a private PostgreSQL 16 cluster under %APPDATA%\VirusAI\data\pg, runs baseline migrations, generates root CA certificates, and spawns the recording proxy on 127.0.0.1:8791.

3. Frictionless Desktop Auto-Login

The native Desktop shell acquires an ephemeral engine authentication token on startup and navigates directly into the IDE workspace. Subsequent warm launches adopt the existing cluster in under 5 seconds.

GOVERNANCE · TARGET PROTECTION

Fail-Closed Scope Gate

The fundamental safety guarantee of VirusAI: out-of-scope network traffic is terminated before a socket connection or DNS query can ever occur.

Strict Ingress / Egress Validation

All traffic initiated by the embedded browser, automated tools, or autonomous agents routes through the internal proxy (127.0.0.1:8791). The proxy inspects the destination against declared project scope rules.

Zero Scope Slip Policy

Any request directed toward an unapproved host is immediately rejected with 403 Forbidden (Out of Scope). There is no bypass toggle in the UI, guaranteeing that operators and agents remain fully compliant with engagement boundaries.

Scope Definition

Operators define target IP ranges, CIDR blocks, or wildcards (e.g. *.target.com) inside project settings or directly within the Proxy Workbench tab.

AUTONOMOUS ASSISTANT · MULTI-SURFACE

Omni Agent HUD (Ctrl+Space)

An integrated reasoning engine with simultaneous multi-surface awareness across code, terminal buffers, browser DOM, and HTTP proxy history.

Non-Intrusive Ergonomic HUD

Press Ctrl+Space at any time to summon or dismiss the Omni Agent HUD. The assistant dynamically squeezes the workspace horizontally instead of covering active code or terminal scrollback.

Evidence Before Assertion

The AI agent never hallucinates vulnerabilities. A finding is only registered when supported by reproducible evidence: control request, attack request, isolated difference diff, and replay confirmation.

Disposable Identity Automation

Built-in disposable email mailbox provisioning with background OTP and magic-link extraction. Enables automated testing of registration flows, password resets, and BOLA/IDOR authorization flaws.

SOVEREIGNTY · LOCAL ENCRYPTION

Local Persistence & Privacy

VirusAI operates on a strict zero-telemetry architecture. All target data, credentials, and traffic streams remain entirely on your local machine.

Filesystem Layout

All operational state lives under %APPDATA%\VirusAI\:

%APPDATA%\VirusAI\
├── data\pg\              # Private PostgreSQL 16 cluster
├── data\traffic\         # Recorded exchanges & CA certificates
├── settings.json         # Loopback ports & workspace preferences
└── engine.log            # Internal supervisor diagnostics

Encrypted Secrets Store

Third-party LLM API keys (OpenAI, Anthropic, OpenRouter, local Ollama) and proxy private keys are encrypted at rest using AES-256-GCM.

DIAGNOSTICS · PORT MANAGEMENT

Port Configuration & Runbook

VirusAI isolates its background processes strictly to loopback interfaces (127.0.0.1) to prevent collisions with host firewalls or external suites.

Default Loopback Ports

- 8790: Engine HTTP API & Embedded Web UI
- 8791: Security Recording MitM Proxy
- 8792: Private Embedded PostgreSQL Cluster

Handling Port Conflicts

If ports 8790–8792 are occupied by other developer tools, customize the port mappings in %APPDATA%\VirusAI\settings.json:

{ "engine_port": 8890, "proxy_port": 8891, "pg_port": 8892 }

HTTPS Proxy Certificate Installation

To intercept and inspect HTTPS traffic, install the dynamically generated root CA into your system certificate store: %APPDATA%\VirusAI\data\traffic\ca.crt.
